  • 💉 Methylprednisolone Dosing Split: แยกโครงสร้างขนาดยา Methylprednisolone ชัดเจนระหว่าง Loading Dose (1–2 mg/kg, cap 60 mg) และ Maintenance Dose (0.5–1 mg/kg/dose q6h, cap 60 mg/dose, 240 mg/day) ป้องกันความสับสนในการสั่งยา

  • 🌐 Universal App Engine & CI Pipeline: ปรับปรุง app.js ให้รองรับ Node.js CommonJS Import และอัปเดต GitHub Actions CI Runner เป็น Node 22 + npm ci
